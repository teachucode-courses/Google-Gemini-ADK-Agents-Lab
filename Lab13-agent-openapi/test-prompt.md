# Agent Test Prompts

- **GET request:** “Use the GET request tool to send the message `Hello from my agent` to httpbin, then show me the response.”
- **POST request:** “Send a POST request with the name `Alex` and message `Testing the API` using the available tool. Show the echoed response.”
- **Get IP:** “Use the IP address tool and tell me the origin IP returned by the API.”
- **Get User-Agent:** “Use the User-Agent tool and show me the value returned by the API.”
